# MechRing Control Protocol v2.0 - Change Summary

## Overview
This document summarizes the changes made to upgrade the MechRing Control Protocol from v1.0 to v2.0.

## Protocol Changes

### 1. Button Field Expansion
- **Changed**: Button field expanded from 8-bit to 16-bit
- **Impact**: Message format changed from `S:<x>,<y>,<2-digit hex>` to `S:<x>,<y>,<4-digit hex>`
- **Reason**: Support for additional virtual buttons and future expansion

### 2. Button Nomenclature Changes
- **Changed**: Physical buttons renamed
  - Button 1 → Button A (bit 0)
  - Button 2 → Button B (bit 1)
  - Button 3 → Button C (bit 2)
  - Button 4 → Button D (bit 3)
  - Recessed Button → Mode Button (bit 10)
- **Impact**: All trigger mappings updated in MechRingTrigger.map

### 3. Virtual Directional Buttons Added
- **Added**: Four virtual buttons generated from joystick position
  - Up (bit 4): Activated when Y > +64
  - Down (bit 5): Activated when Y < -64
  - Left (bit 6): Activated when X < -64
  - Right (bit 7): Activated when X > +64
- **Threshold**: ±64 (~50% joystick deflection)
- **Implementation**: Virtual buttons generated by MechRing firmware before transmission

### 4. Battery Voltage Reporting Removed
- **Removed**: Battery voltage field eliminated from protocol
- **Rationale**: Unused feature, simplifies protocol
- **Impact**: All battery monitoring code removed from both projects

## Button Bit Layout (16-bit)

| Bit | Button Name | Type | Description |
|-----|-------------|------|-------------|
| 0 | Button A | Physical | Formerly Button 1 |
| 1 | Button B | Physical | Formerly Button 2 |
| 2 | Button C | Physical | Formerly Button 3 |
| 3 | Button D | Physical | Formerly Button 4 |
| 4 | Up | Virtual | Y > +64 |
| 5 | Down | Virtual | Y < -64 |
| 6 | Left | Virtual | X < -64 |
| 7 | Right | Virtual | X > +64 |
| 8 | Trigger | Physical | Analog trigger button |
| 9 | Joystick Press | Physical | Joystick click |
| 10 | Mode | Physical | Formerly Recessed Button |
| 11-15 | Reserved | - | Available for future use |

## Example Messages

### Before (v1.0)
```
S:0,0,00,3.7        # Idle state with battery voltage
S:0,64,01,3.7       # Button 1 pressed, Y=64
S:-50,0,11,3.6      # Button 1 + Recessed, X=-50
```

### After (v2.0)
```
S:0,0,0000          # Idle state
S:0,64,0001         # Button A pressed, Y=64
S:-50,0,0401        # Button A + Mode, X=-50
S:0,80,0011         # Button A + Up (virtual), Y=80
S:-70,0,0041        # Left (virtual), X=-70
```

## Breaking Changes
This is a **breaking change** from v1.0 to v2.0:
- Message format is incompatible (2-digit vs 4-digit hex)
- Button trigger names changed in configuration
- No backward compatibility maintained

Both MechRing firmware and MechMind brain must be updated together.

## Future Considerations
- Bits 11-15 reserved for future expansion (5 additional buttons/flags possible)
- Virtual button threshold (64) could be made configurable
- Protocol version negotiation could be added for future compatibility
